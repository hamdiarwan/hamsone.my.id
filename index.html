Discord shop bot • QRIS • Live

      
Disokin Store

      
Problem: A shop owner had to reply manually, track stock himself, and missed orders while sleeping.

      
Solution: A Discord bot with /stock, /buy, a 10-minute stock lock, QRIS payment via webhook, delivery via DM, and an admin dashboard.

      
Result: Live since 29 October 2026. The first real buyer order was delivered via DM. Showcased with the owner's permission.

      
    
        
  • Before: The owner missed orders while asleep — replies and stock were manual.
    • 
        
  • Build: Bot, admin dashboard, and QRIS webhook — tested on my own server first.
    • 
        
  • Go-live: 29 October 2026, on the owner's server.
    • 
        
  • First order: The same evening, delivered via DM.
    • 
      

      
Price shown in the shop: Rp65,000 per account. That is the shop's live price, not a public price list for new clients.
